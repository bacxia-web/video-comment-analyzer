YouTube subtitles

Optional fallback when YouTube page subtitles cannot be read. Translation and bilingual reading do not require this key. Get a Supadata API Key. Copy the key from your Supadata account and paste it above.

Free plan: 100 credits per month, no credit card needed. Fetching existing subtitles costs 1 credit per request, so this allows about 100 requests. Unavailable subtitles may still cost a credit. Unused credits do not carry over. This extension does not transcribe videos without subtitles. Official pricing and quota · Request cost

YouTube comments

Needed only to fetch YouTube comments and replies. Other features work without it. Select or create a Google Cloud project, then complete these steps: 1. Enable YouTube Data API v3 · 2. Create an API Key. Paste the key above.

Default free quota: 10,000 units per project per day. One request costs 1 unit and returns up to 100 top-level comments. More pages and replies use additional units. Other calls in the same project may share this quota. Official quota · Request cost
